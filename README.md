# Hangman Game

A simple Python Hangman game where the player tries to guess a randomly selected word one letter at a time.

## Features

* Randomly selects a word
* Shows hidden letters as underscores
* Tracks guessed letters
* Gives 6 attempts
* Reveals correct letters
* Handles invalid and repeated guesses
* Displays the final result

## Technologies Used

* Python
* Random module

## How to Run

1. Make sure Python is installed.
2. Run the program using:

```bash
python hangman.py
```

3. Enter one letter at a time to guess the word.
